                READ / 快速上手
                
操作说明

                
导入滤镜与更新补丁，各三步。写卡类操作均需明确授权，照片不写入。

              


              

                
流程一 / 导入滤镜

                

                  1
                  
选择滤镜文件
在「导入滤镜」页，把 .cube / .3dl / .csp / .xmp 或 Hald 图像拖入，或点击「选择 LUT 文件」。支持多选，逐文件报告结果。XMP 仅近似转换全局调色，未转换项见结果日志，不等同于 Adobe 原效果。

                

                

                  2
                  
调参数并保存
设置影调（直出 / 中灰 / 混合）与强度，右侧「预览与结果」对比满意后点「保存改动」入库。

                

                

                  3
                  
加入卡清单并写卡
在卡清单加入该滤镜、设置相机名称，确认写卡后才在相机生效。写卡前只读预检、本地备份、写完回读校验。

                

              


              

                
流程二 / 更新补丁

                

                  1
                  
选相机类型
在「更新补丁」页按机身原本型号选择 L口 / L口改C口 或 纯C口。L 口改了 C 口仍算 L 口；以固件判断，不看接口外形。

                

                

                  2
                  
插入存储卡并预检
关机取卡、插入电脑，点「重新扫描」识别目标卡。核对安装计划与保护内容（照片 / 已有触屏设置 / 滤镜记忆）。

                

                

                  3
                  
确认安装并回装
点「一键安装整包」并确认。完成后正常弹出卡、装回相机，开机等约 3 秒再触屏。已保留 DCIM 与 touch_prefs.bin。
